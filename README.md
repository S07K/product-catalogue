## Run it

```bash
git clone -b feat/product-catalogue https://github.com/S07K/product-catalogue.git
cd product-catalogue
docker compose up --build
```

- App: http://localhost:8080
- Sales inbox (enquiry emails, dev-only Mailpit): http://localhost:8025

Full setup, test instructions and documentation are in the branch's [README](https://github.com/S07K/product-catalogue/blob/feat/product-catalogue/README.md), plus [DECISIONS.md](https://github.com/S07K/product-catalogue/blob/feat/product-catalogue/DECISIONS.md) and [AI_USAGE.md](https://github.com/S07K/product-catalogue/blob/feat/product-catalogue/AI_USAGE.md).
